# 저장·훈련장·플레이어 스킬 구현 완료

팀 Unity 버전은 **6000.3.23f1**이다. 기존 저장·플레이어·공격·UI 구조를 재사용하고, Unity 버전·Packages·렌더 파이프라인을 변경하지 않았다.

## 1. 저장 시스템: 구현 중 → 구현 완료

- 침대에서만 수동 저장하고, 실제 파일 교체 성공 뒤에 저장 완료를 표시한다.
- 시작 메뉴의 새 게임·이어하기·덮어쓰기·삭제 확인을 연결했다. 미저장 플레이는 마지막 수동 저장을 덮어쓰지 않는다.
- 장비·인벤토리·퀵슬롯·플레이어 성장·HP/MP·재화·시설·무기 ID별 허수아비 보너스·퀘스트 진행과 보상 수령 상태를 보존한다.
- 임시 파일 flush, SHA-256 검증, 이전 파일 백업, 손상·미지원 저장 거부, 이전 저장 형식 읽기를 지원한다.
- 기존 숲의 중복 인벤토리 UI 직렬화를 정리하고, 현재 설계 UI와 이어하기용 플레이어 프리팹을 사용한다.
- 현재 기지의 일반 나가기 목적지는 기존 작업에서 정한 `Market`이며 임시 목적지다. 훈련장 복귀와 저장 복원은 이 일반 나가기 버튼과 별도로 동작한다.

세부 규격·사용 순서·기존 검증 자료: [수동 저장 구현 안내](ManualSaveImplementation.md).

## 2. 허수아비 2D 훈련장

- 이미 존재한 `Assets/Scenes/HideOutSystemScene/ScareCrowScene/ScareCrowScene.unity`를 완성했다. 같은 역할의 씬을 중복 생성하지 않았고 기존 GUID를 유지했다.
- 월드 아이콘과 하단 바로가기를 같은 진입점으로 연결했다. 기존 시설 카메라 이동·확대를 마친 뒤 검은 화면에서 비동기 씬 준비를 완료하고 다시 밝힌다. 페이드는 양쪽 각각 기본 0.4초다.
- 기존 플레이어 하나를 사용하고 장착 무기·성장·인벤토리·재화·HP/MP를 유지한다. 바닥·벽·매트·경계·장식·시작 위치와 과녁 허수아비 한 개를 씬에 저장했다.
- 실제 공격의 확정 최종 데미지를 숫자로 표시한다. HP 잔량으로 숫자가 잘리지 않고, 일반·강한 타격·전달된 실제 크리티컬 정보를 구분한다.
- 현재 실제 크리티컬 판정기는 없으므로 임의 추첨하지 않는다. 강한 데미지 연출의 기본 기준은 20이며 수치를 변경하지 않는다.
- 숫자 풀링, 외형만 흔들리는 피격 반응, 짧은 밝아짐과 스파크를 적용했다. 보상·경험치·일반 적 처치 기록은 만들지 않는다.
- 기존 시설 강화 패널을 재사용한다. ESC는 기존 인벤토리 정책을 존중하고 시설 패널을 먼저 닫은 뒤 기지로 복귀한다.

연출 설정·아트 교체·연결 위치: [훈련장 안내](../Assets/Scenes/HideOutSystemScene/ScareCrowScene/ScareCrowTrainingNotes.md).

## 3. 플레이어 스킬

- **Q/C 은신:** 지속 2.5초, 기존 쿨타임 12초와 MP 15 유지. 실제 첫 근접 스윙에 최종 데미지 +10을 한 번 적용하므로 기본 공격 10은 20이 된다. 기존 무기·성장·시설 보너스는 유지한다.
- **E/V 수류탄:** 기본 5개. 누르면 각도와 포물선 궤적을 표시하고, 놓을 때 1개를 소모해 투척한다. 각도는 20°~75°를 오가며, 기본 투척 간격은 0.45초다.
- **폭발:** 1.6초 후 범위 2.4 안의 적·허수아비에 24 데미지를 한 번씩 적용한다. 중복 Collider는 중복 타격하지 않는다.
- **자폭:** 위험 범위 1.6에서 기존 플레이어 피격 함수를 사용한다. 공격력 15이므로 기본 방어력 11 기준 4 HP 피해다.
- **소진과 유지:** 다섯 번째 투척 직후 소진 메시지를 표시한다. 씬 이동·재활성화로 보충하지 않고 기존 저장 확장에 잔여 개수를 보관한다.
- **충격파 보관:** 기존 코드와 설정을 유지하고 E/V 입력과 HUD 연결만 수류탄으로 교체했다.

설정·조작·임시 외형 교체: [플레이어 스킬 안내](../Assets/Player/PlayerSkillsNotes.md).

## 검증과 배포 범위

- Unity 6000.3.23f1의 기존 에디터에서 스킬 검사 **56개**, 훈련장 통합 검사 **48개**가 통과했고 각 실행의 런타임 오류는 **0개**였다.
- 2026-11-06 저장 통합 검사 **51개**, Play 재시작 디스크 복원 검사 **12개**, 씬 연결 검사 **4개**를 다시 통과했다. [저장 검증 자료](ManualSaveImplementation.md#검증-증거)를 함께 기록한다.
- 최신 기존 기지 회귀 검사 **132개**를 통과했다. 실행 시 로드된 미리보기/검사 대상 수에 따라 이전 실행은 133개였으며, 최신 결과를 기준으로 기록한다.
- 새 테스트는 실제 저장 슬롯을 덮어쓰지 않는다. 작업 전 변경 파일과 미추적 파일은 프로젝트 Temp에 해시 검증 백업을 만들었다.
- 자동 생성된 동적 폰트 atlas 캐시와 로컬 테스트의 `runInBackground` 변경은 기능 커밋과 분리해 원래 작업 폴더에 보존한다.
- 출시 Windows 실행 파일의 종료·재실행, 최종 아트·효과음, 장시간 조작감과 밸런스는 수동 확인이 남아 있다. 에디터 자동 검증을 해당 수동 검증으로 표현하지 않는다.

커밋은 코드 참조를 충족하도록 저장 완료, 플레이어 스킬·전투 연결, 훈련장 순서로 구성한다. 설명은 위의 세 기능 영역을 기준으로 제공한다. Git 이력을 강제로 다시 쓰거나 원격 브랜치를 강제 push하지 않는다.
