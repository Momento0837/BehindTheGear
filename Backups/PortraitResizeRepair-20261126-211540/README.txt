기존 Dialogue JSON의 각 대사에서 "표정" 값만 바꾸면 됩니다.

예시:
{ "speaker": "Ethan", "표정": "곤란", "text": "대사 내용" }
{ "speaker": "Selena", "표정": "의아", "text": "대사 내용" }

사용 가능한 값
이든: 기본 표정, 곤란, 의아, 짜증, 눈 돌림, 눈 반 감음, 눈 감음, 엥
셀레나: 기본 표정, 의아, 흘겨봄

이미지는 이 폴더 또는 Assets/!Pictures에 아래 파일명으로 추가하세요. 공백도 그대로 사용합니다.
이든_곤란.png
이든_의아.png
이든_짜증.png
이든_눈 돌림.png
이든_눈 반 감음.png
이든_눈 감음.png
이든_엥.png
셀레나_의아.png
셀레나_흘겨봄.png

이 폴더의 새 PNG는 Sprite로 가져오며, 같은 이름의 표정과 자동으로 연결됩니다.
!Pictures의 이미지는 기존 Import 설정을 유지합니다. Sprite로 등록되어 있어야 하며,
Multiple 모드도 스프라이트가 하나로 잘려 있으면 그대로 연결됩니다.
이든_새표정.png 또는 셀레나_새표정.png를 추가하면 해당 표정 이름도 자동 등록됩니다.
Portraits.asset에 직접 연결한 이미지는 자동 연결이 덮어쓰지 않습니다.
기본 표정은 기존 !Pictures의 두상을 사용합니다.
이미지가 없는 표정, 알 수 없는 표정 또는 표정 항목이 없는 대사는 기본 두상을 표시합니다.
???의 기존 애니메이션 초상화는 이 설정의 영향을 받지 않습니다.
Resources/Dialogue/Portraits.asset에서 이미지를 직접 연결할 수도 있습니다.
