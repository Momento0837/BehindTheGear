# 아이템 설정

`inventory_ui_text.json`은 이제 아이템 설정만 담습니다. UI 레이아웃/스탯 설명 등은 기존 프리팹과 stat_tooltips.json에서 관리합니다.

각 items 항목:
- `id`: 아이템 에셋 Item Id와 반드시 같아야 합니다. **망토는 tutorial_gear**입니다. 이름을 바꾸려면 id 대신 display.name을 수정하세요.
- `display.name`: 이름. 빈 문자열이면 에셋 이름을 사용합니다.
- `display.description`: 설명. 빈 문자열이면 설명도 비워집니다. 줄바꿈은 \n.
- `rarity`: Normal / Advanced / Rare / Legendary. Status의 기존 Advenced 표기는 유지됩니다.
- `stats.increase`: 각 능력치 증가량(0 이상의 정수).
- `stats.decrease`: 각 능력치 감소량(0 이상의 정수).
- 능력치 키: Evasion(회피), Stealth(은신), Attack(공격), Defense(방어), Persuasion(설득).

증가와 감소는 툴팁에서 따로 표시합니다. 장착 중 실제 적용값은 증가 - 감소이며, 최종 플레이어 스탯은 0 미만으로 내려가지 않습니다. 직접 배분한 스탯과 장비 보너스는 구분됩니다. - 버튼은 직접 배분한 스탯을 줄이고 포인트 1을 반환합니다.

Status의 희귀도 숫자는 가방 및 퀘스트 가방 안의 **수량 합계**입니다. 장착 중인 아이템은 제외하며, Count는 기존대로 점유 칸 수입니다. 공백, 줄바꿈, 라벨은 프리팹 원문을 유지합니다.

Unity에서 JSON 저장/임포트 후 플레이 중에도 약 0.5초 내 UI가 갱신됩니다. 빌드에서는 수정한 JSON을 포함해 다시 빌드해야 합니다. 잘못된 JSON은 콘솔 오류를 표시하고 마지막 정상 설정을 유지합니다.
현재 수치와 희귀도는 기존 설정을 유지하도록 0 / Normal로 시작합니다. 원하는 밸런스 수치를 입력하세요.
