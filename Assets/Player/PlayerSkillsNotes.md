# 은신과 수류탄

## 조작과 초기 밸런스

- WASD 조작: Q 은신, E 누르고 조준 → 놓아서 수류탄 투척.
- 방향키 조작: C 은신, V 누르고 조준 → 놓아서 수류탄 투척.
- 은신 지속 시간 2.5초, 기존 쿨타임 12초·MP 15 유지.
- 은신에서 시작한 첫 근접 공격은 최종 무기 데미지에 +10. 기본 공격 10이면 20이며, 무기·성장·허수아비 강화 보너스도 유지한다. 크리티컬을 임의로 생성하지 않는다.
- 수류탄 초기 보유 5개, 한 번에 1개 투척, MP 소모 없음, 투척 간격 0.45초.
- E/V를 유지하면 조준각이 20°~75° 사이를 오간다. 편도 조정 시간은 1.1초이며, 놓는 순간 보이는 각도로 투척한다. 이동 방향으로 던질 방향을 바꿀 수 있다.
- 속도 10.5, 중력 배율 1.6, 투척 후 1.6초에 폭발한다. 바닥·벽에 닿으면 약하게 튕기며, 폭발은 타이머를 따른다.
- 폭발 데미지 24, 범위 2.4. 범위 안에 있는 모든 적·허수아비를 한 번씩 타격한다. Collider가 여러 개여도 대상당 한 번만 처리한다.
- 플레이어 위험 범위는 1.6, 자폭 공격력은 15. 기존 `PlayerHealth.TakeDamage`를 사용하므로 기본 방어력 11 기준 4 HP 피해다. 기존 무적 시간·사망 처리도 유지한다.
- 다섯 번째 투척 즉시 `수류탄을 모두 소진했습니다.`를 표시한다. 보유량 0에서는 여섯 번째 수류탄이 생성되지 않는다.
- 조준 취소·비활성화·조작 방식 변경·씬 이동은 탄약을 소모하지 않는다. 씬 이동이나 컴포넌트 재활성화로 수류탄을 보충하지 않는다. 새 플레이어는 5개로 시작한다.

## 코드 연결

`PlayerAttackController`가 기존 `PlayerSkills`와 새 `PlayerGrenadeSkill`을 같은 플레이어에 연결한다. `PlayerInputReader.SkillTwoPressed`는 조준 시작, `SkillTwoReleased`는 투척에 연결된다. 실제 투척 시 기존 두 번째 스킬 UnityEvent를 호출한다.

`PlayerMeleeAttack.BeginComboSwing`은 실제 공격이 시작될 때 은신 보너스를 한 번 확보하고 은신을 해제한다. 실제 애니메이션 타격 시 최종 무기 데미지와 합산한다. 동일한 스윙의 여러 대상에는 동일한 최종 수치를 적용하고, 다음 스윙에는 보너스가 남지 않는다. 취소된 스윙의 보너스도 제거한다. 기존 공격 애니메이션·타격 시점은 바꾸지 않는다.

`PlayerGrenadeProjectile`은 Rigidbody2D·CircleCollider2D로 비행하고, 폭발 시 기존 몬스터 피격 함수와 `IMeleeDamageReceiver/ICombatHitReceiver`를 사용한다. 허수아비 숫자도 확정된 24 데미지를 그대로 받는다. 플레이어와 투사체의 물리 충돌만 제외하며 폭발의 자폭 판정은 유지한다.

`InGameSkillHUD`는 기존 슬롯 배치를 유지하고 E/V 이름·조준각·잔여 개수를 표시한다. 소진 안내는 기존 한글 폰트와 공유 TMP Material을 사용하는 작은 메시지로 표시한다.

기존 충격파는 `PlayerSkills.TryUseShockwave()`와 관련 Inspector 설정·피격 처리를 그대로 보관했다. E/V와 HUD 연결을 수류탄으로 바꿨으며, 향후 별도로 다시 연결할 수 있다.

## 상태 유지와 Inspector 설정

`PlayerGrenadeSkill`은 기존 `IHideOutSaveParticipant`를 구현한다. 저장 키는 `player_grenades_v1`이며, 기존 저장 스냅샷의 extensions에 남은 개수를 보관한다. 새 저장 시스템이나 자동 저장은 추가하지 않았다.

Play 중 실제 플레이어의 `PlayerSkills`에서 은신 시간·MP·첫 공격 보너스를 조절할 수 있다. `PlayerGrenadeSkill`에서는 개수·투척 간격·각도·속도·중력·폭발 시간·범위·데미지·자폭 공격력을 조절한다. 현재 두 컴포넌트는 기존 방식대로 런타임에 연결되므로 영구 기본값은 스크립트의 SerializeField 초기값이다. 기존 프리팹에 컴포넌트를 직접 붙여 직렬화하면 해당 Inspector 값을 사용할 수도 있다.

`grenadeSprite`가 비어 있으면 단순한 녹색 몸체와 주황색 심지의 임시 스프라이트를 만든다. 정식 스프라이트는 이 필드에 연결한다. 조준선과 폭발 링은 기존 URP·효과 방식을 사용한다. 원본 폰트·Material·패키지·Unity 버전을 변경하지 않는다.

## 검증

Unity 6000.3.23f1에서 기존 에디터를 사용한다. `Tools > Checks > Player Q E Skills`는 격리된 런타임 검사이며 실제 저장 파일이나 씬을 저장하지 않는다. 결과는 `Temp/PlayerSkillValidation/result.txt`, 진행 내용은 `progress.txt`에 기록한다.

2026-11-06 스킬 검사: 56개 통과, 런타임 오류 0개. 실제 Q/E 및 C/V 입력, 은신 만료와 첫 공격 보너스, 기존 충격파 보관, 각도 조정, 실제 포물선 비행과 시간제 폭발, 여러 적과 중복 Collider, 자폭·안전 거리, 5개 소진 및 HUD, 비활성화 후 개수 유지, 저장 개수 검증을 확인했다.

훈련장 통합 검사 48개도 통과했고 런타임 오류는 0개였다. 기존 장착 무기의 실제 애니메이션에서 은신 보너스를 전달하고, 수류탄의 실제 타이머 폭발이 허수아비에 24 데미지와 숫자 하나를 표시하며, 기존 저장 확장이 잔여 4개를 기록하고 기지 왕복 후에도 4개를 유지하는 것을 확인했다. 촬영 화면은 `Temp/ScareCrowValidation/training-grenade-aim.png`와 `training-grenade-blast.png`이다.

훈련장 통합 검사는 `Tools > HideOut > Verify ScareCrow training room`과 `Temp/ScareCrowValidation/`을 참고한다. 출시 빌드 조작감, 최종 아트·효과음과 장시간 밸런스는 수동 확인 대상이다.
