# 퀘스트 문구 직접 수정하기

`Assets/Resources/Quests` 폴더의 JSON 파일을 메모장이나 Visual Studio에서 수정하고 UTF-8로 저장하세요.
진행 순서, 처치 조건, 망토 획득·장착 조건은 그대로이며 **제목과 설명만 수정**합니다.

## 어떤 파일을 수정하나요?

| 게임에서 표시되는 시점 | 파일 |
| --- | --- |
| 포레스트 전투 시작 | `forest_combat.json` |
| 몬스터 처치 완료, 포레스트 탈출 | `forest_exit.json` |
| 가베지에서 망토 찾기 | `garbage_search.json` |
| 망토 획득 후 장착 안내 | `equipment_tutorial.json` |
| 망토 장착 후 가베지 탈출 | `garbage_exit.json` |
| 마켓 NPC에게 대화하기 | `market_talk.json` |
| NPC 의뢰 거절 후 재대화 | `market_retry.json` |
| NPC 의뢰 수락 | `market_quest.json` |
| 별도 수집 퀘스트 NPC | `collection_quest.json` |

## 수정 예시

```json
{
  "questName": "낡은 망토 두르기",
  "objective": "I 키로 인벤토리를 열고\n발견한 망토를 장착하세요.",
  "showObjective": true
}
```

- `questName`: 화면에 나오는 퀘스트 제목입니다.
- `objective`: 자세한 설명입니다.
- `showObjective`: `true`면 제목 아래에 설명도 표시합니다. `false`면 기존처럼 제목만 표시합니다.
- 원하는 곳에서 줄을 바꾸려면 문자열 안에 `\n`을 넣으세요. 실제 줄바꿈을 따옴표 안에 직접 입력하지 마세요.
- 문장 안의 큰따옴표는 `\"`로 씁니다. 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
- 파일 이름과 `questName`, `objective`, `showObjective`라는 항목 이름은 유지하세요. 값만 바꾸면 됩니다.

## 자동 정렬

제목의 16자 말줄임 제한을 없앴습니다. 짧으면 내용에 맞게 폭이 줄고, 길면 화면 오른쪽 기준으로 자동 줄바꿈됩니다.
텍스트 영역은 아래쪽으로 늘어나며 느낌표 아이콘의 위치와 크기는 유지됩니다.
화면 폭에 맞춰 최대 너비를 제한하고, 여러 줄이 너무 길어지면 글자 크기를 줄입니다.
기존 폰트·재질과 등장/완료 효과는 유지하며, 여러 줄은 위에서 아래로 애니메이션됩니다.
가독성을 위해 제목은 짧게, 긴 안내는 `objective`에 넣는 편이 좋습니다.

## 변경 적용

1. Unity **6000.3.23f1**에서 플레이를 종료합니다.
2. 원하는 JSON을 수정하고 저장합니다.
3. Unity로 돌아와 파일 반영이 끝나면 다시 플레이합니다.

이미 표시 중인 퀘스트 문구를 실시간으로 갱신하는 기능은 아닙니다. 다음에 해당 단계가 시작될 때 JSON을 읽습니다.
완료 조건이나 순서를 바꾸거나 새 종류의 퀘스트를 추가하는 작업은 별도의 코드 수정이 필요합니다.

JSON 오류가 있으면 Console에 해당 파일 이름과 오류를 표시하고, 기존 퀘스트 표시를 유지합니다.
