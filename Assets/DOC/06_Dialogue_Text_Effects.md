# 대화 글자 흔들림·먼지 효과 설정

`Quest Giver NPC - Shaking Dialogue`에 적용된 `DialogueTextEffects` 컴포넌트의 Inspector 설정입니다. 데모 씬 `Assets/Player/PlayerMovementDemo.unity`에서 해당 NPC를 선택한 뒤 **Dialogue Text Effects**를 열어 조절할 수 있습니다. 현재 이 효과는 해당 NPC의 대화에만 연결되어 있습니다.

## Character shake: 글자 흔들림

글자가 한 글자씩 출력되는 동안 각 글자가 흔들립니다. 한 줄의 출력이 끝나면 앞 글자부터 뒤 글자 순서로 흔들림이 줄어듭니다.

| Inspector 항목 | 현재 값 | 효과 |
| --- | ---: | --- |
| `Shake Amplitude` | 1.5 | 글자가 움직이는 폭. 높일수록 흔들림이 커집니다. `0`이면 흔들리지 않습니다. |
| `Shake Frequency` | 28 | 흔들리는 속도. 높일수록 더 빠르게 떨립니다. |
| `Settle Wave Duration` | 0.7초 | 한 줄 출력이 끝난 뒤, 첫 글자부터 마지막 글자까지 **멈추기 시작하는 시점**이 퍼져 나가는 시간. 높일수록 순차적으로 멈추는 과정이 길어집니다. |
| `Settle Duration` | 0.4초 | 각 글자가 멈추기 시작한 후 흔들림이 완전히 사라지는 데 걸리는 시간. 높일수록 부드럽고 천천히 멈춥니다. |

현재 값에서는 줄 출력이 끝난 뒤 0.7초에 걸쳐 글자들이 차례로 안정되기 시작하고, 각 글자의 흔들림은 그 시점부터 0.4초 동안 줄어듭니다.

## Falling dust: 떨어지는 먼지

공백이 아닌 글자가 나타날 때 그 글자 주변에 먼지가 생성됩니다. 먼지는 아래로 떨어지면서 점점 투명해지고 사라집니다.

| Inspector 항목 | 현재 값 | 효과 |
| --- | ---: | --- |
| `Dust Per Character` | 3 | 글자 하나가 나타날 때 생성되는 먼지 개수. |
| `Dust Color` | 갈색 | 먼지의 색과 초기 투명도. 색상 선택기의 알파 값으로 투명도를 조절합니다. |
| `Dust Min Size` | 5 | 먼지 한 알의 최소 크기. |
| `Dust Max Size` | 8 | 먼지 한 알의 최대 크기. 각 먼지는 **5~8 사이에서 무작위** 크기로 생성됩니다. |
| `Dust Min Lifetime` | 0.48초 | 먼지가 남아 있는 최소 시간. |
| `Dust Max Lifetime` | 0.72초 | 먼지가 남아 있는 최대 시간. 각 먼지는 **0.48~0.72초 사이에서 무작위** 시간 동안 보입니다. |
| `Dust Gravity` | 110 | 아래로 떨어지는 가속도. 높일수록 떨어지는 속도가 더 빠르게 증가합니다. |

`Min`은 최솟값, `Max`는 최댓값입니다. 크기와 지속시간을 일정하게 만들고 싶다면 각각의 최솟값과 최댓값을 같게 설정하면 됩니다. 최대 크기와 최대 지속시간은 각 최솟값보다 작아지지 않도록 자동으로 보정됩니다.
