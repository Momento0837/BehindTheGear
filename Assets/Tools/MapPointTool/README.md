# Map Point Tool — 2D 맵 스폰 포인트 에디터

2D 사이드뷰 맵 프리팹 위에서 **플레이어 스폰 / 몬스터 스폰 / 포탈 / 미니보스** 위치를 클릭으로 찍고,
Empty Object로 구성된 프리팹(`{맵이름}_Points_vN.prefab`)으로 내보내는 Unity 에디터 확장입니다.

- Unity **6000.3.23f1** (Unity 6.3 LTS) 기준으로 작성·검증
- 에디터 전용(Editor 어셈블리)이라 **빌드에 포함되지 않고**, 런타임 스크립트 의존도 없습니다
- 외부 패키지 의존 없음(UnityEditor / UnityEngine만 사용)

---

## 열기

`Tools ▸ BehindTheGear ▸ Map Point Tool ▸ Open`

```
┌──────────────┬──────────────────────────────────────┬────────────────┐
│ 맵 프리팹 목록 │ [선택 Q][●플레이어 1][●몬스터 2]…     │ 맵 정보         │
│ (Assets/!Map) │                                      │ Z 정렬 기준     │
│  썸네일       │        맵 미리보기 캔버스               │ 선택한 포인트    │
│  버전 개수    │   (스프라이트를 정렬 순서대로 그림)      │ 포인트 목록     │
│              │                                      │ 확인 필요       │
│ 다른 프리팹…  │ 편차 Δ(x,y) → 좌표(x,y)  줌  개수      │ 내보내기 / 버전  │
└──────────────┴──────────────────────────────────────┴────────────────┘
```

## 사용 순서

1. **맵 선택** — 왼쪽 목록(기본 `Assets/!Map`)에서 프리팹을 클릭합니다.
   `다른 프리팹 열기…`로 파일을 고르거나, 프리팹을 창에 끌어다 놓아도 됩니다.
2. **포인트 찍기** — 상단에서 종류(1~4)를 고르고 맵을 클릭합니다. 클릭한 채로 끌면 바로 위치를 조정할 수 있습니다.
3. **Z 기준 확인** — 오른쪽 `Z 정렬 기준`에서 레이어를 고릅니다. 기본값은 **Sorting Layer = Default**
   (이 프로젝트 맵의 게임플레이 레이어)이며, 프로젝트에 정의된 레이어 목록을 Unity API로 직접 읽어 옵니다.
4. **내보내기** — 모드를 고르고 `내보내기` 버튼을 누르면 원본 맵과 같은 폴더에 새 버전이 저장됩니다.

### 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 | 포인트 추가(종류 선택 시) / 선택·드래그 |
| 휠 | 커서 기준 확대·축소 |
| 가운데·오른쪽 드래그, Alt+좌드래그 | 화면 이동 |
| 오른쪽 클릭 | 컨텍스트 메뉴(여기에 추가, 종류 변경, 복제, 삭제) |
| `Q` / `1`~`4` | 선택 도구 / 포인트 종류 |
| `Del` · `Ctrl+D` · `F` | 삭제 · 복제 · 맵 전체 보기 |
| `G` · `S` | 그리드 · 스냅 켜기/끄기 |
| `Ctrl+Z` / `Ctrl+Y` | 모든 편집 되돌리기/다시 실행 |

## 좌표 계산 규칙

화면의 **중앙(0, 0)** 은 선택한 맵 프리팹의 **루트 좌표**입니다.

```
편차 Δ      = 클릭한 위치 − 맵 중앙
최종 X, Y   = 맵 프리팹 루트 좌표(X, Y) + Δ
최종 Z      = 기준 레이어(기본: Sorting Layer "Default") 스프라이트의 월드 Z
```

예) `#1_Forest` 루트 `(0, 4.87, -9.2)`, Default 레이어 `Near`의 월드 Z `-5.5`
→ Δ`(2, -1)`에 찍은 포인트 = **`(2, 3.87, -5.5)`**

## 내보내기 모드

| 모드 | 결과물 | 원본 맵 |
|---|---|---|
| **포인트만** | 루트 `(0,0,0)` + 포인트 Empty Object(절대 좌표). 맵과 같은 씬에 원점으로 두면 위치가 맞습니다. | 변경 없음 |
| **맵 + 포인트** | 맵 프리팹을 **복제(새 GUID)** 하고 그 안에 포인트를 추가 | 변경 없음 |

두 모드 모두 결과물 구조가 같아서, 런타임 코드에서 같은 방식으로 찾을 수 있습니다.

```
#1_Forest_Points_v3            ← 파일 이름 = {맵 이름}_Points_v{N}
└─ MapPoints
   ├─ PlayerSpawns   └─ PlayerSpawn_01
   ├─ MonsterSpawns  ├─ MonsterSpawn_01
   │                 └─ MonsterSpawn_02
   ├─ Portals        └─ Portal_01
   └─ MiniBosses     └─ MiniBoss_01
```

- **버전 번호**: 폴더 안의 `{맵 이름}_Points_v{숫자}`를 찾아 **가장 큰 숫자 + 1**로 저장합니다(v1, v2, v3 …).
  중간 번호가 비어 있어도 덮어쓰지 않고, 기존 파일은 절대 덮어쓰지 않습니다.
- **다시 불러오기**: `이 맵의 포인트 버전` 목록에서 `불러오기`를 누르면 이전 버전의 포인트를 편집기로 가져옵니다.
- 내보낸 `_Points_v*` 프리팹은 맵 목록에서 자동으로 제외됩니다.

## 팀원에게 배포하기

**방법 A — .unitypackage (권장)**
`Tools ▸ BehindTheGear ▸ Map Point Tool ▸ 팀원 배포용 .unitypackage 만들기` → 파일 하나를 전달하고,
받는 쪽은 `Assets ▸ Import Package ▸ Custom Package…`로 가져오면 됩니다.

**방법 B — 폴더 복사 / UPM**
`MapPointTool` 폴더를 다른 프로젝트의 `Assets/` 아래에 복사합니다.
`package.json`이 들어 있으므로 프로젝트의 `Packages/` 폴더로 옮기면 로컬 UPM 패키지로도 인식됩니다.

### 설계 포인트

- **미리보기는 직접 그립니다.** URP 2D 조명·카메라 설정에 관계없이 항상 같은 화면이 나오도록,
  SpriteRenderer를 Sorting Layer → Order in Layer → Z 순서로 정렬해 IMGUI로 그립니다(회전·스케일·Flip·색상 반영).
- **원본 보호.** 원본 맵 프리팹은 열기만 하고 수정하지 않습니다. 실패한 내보내기는 이번에 만든 파일만 정리합니다.
- **Empty Object만 사용.** 포인트는 Transform만 가진 GameObject라서 런타임 스크립트가 없어도 되고,
  어떤 스포너 코드에서도 `transform.Find("MapPoints/MonsterSpawns")`처럼 바로 쓸 수 있습니다.

### 알려진 제한

- 미리보기는 SpriteRenderer만 그립니다(Tilemap 등 다른 Renderer는 그려지지 않지만 Z 기준 후보에는 포함).
- 커스텀 셰이더 효과, 런타임 패럴랙스 이동은 미리보기에 반영되지 않습니다(에디터에 저장된 배치 기준).
